机器人触发，支持写三个时间参数。
AutoScript.txt文件
单个时间参数
[*:*:*] 脚本名           # 每秒执行
[*:*] 脚本名            # 每分钟执行
[2024-01-20] 脚本名     # 指定日期执行
[0] 脚本名              # 每周日执行
两个时间参数
[*:*:*] [*:*] 脚本名           # 第一个参数会被忽略，因为第二个会覆盖
[2024-01-20] [12:30] 脚本名   # 2024年1月20日12点30分执行
[2024-01-20] [0] 脚本名       # 2024年1月20日且是周日执行
三个时间参数
[2024-01-20] [12:30] [45] 脚本名    # 2024年1月20日12:30:45执行
[2024-01-20] [0] [12:30] 脚本名    # 2024年1月20日周日12:30执行
常见写法：
[*:*:*] 脚本名	解释：每秒执行
[*:*] 脚本名	解释：每分钟执行
[*:*:0] 脚本名	解释：每分钟0秒执行
[*:0] 脚本名	解释：每小时0分执行
[0] 脚本名	解释：每周日执行
[2024-01-20] [12:30:45] 脚本名	解释：2024年1月20日12:30:45执行一次
注意：时间格式类型。
支持的格式
1. 日期格式 (3个部分，用 - 分隔)
[年-月-日] 例如： [2024-01-20]
[*-*-*] - 表示每一年/月/日
[2024-*-*] - 2024年的每一天
[*-01-*] - 每年的1月每一天
[*-*-20] - 每月20日
2. 时间格式 (3个部分，用 : 分隔)
[时:分:秒] 例如： [12:30:45]
[*:*:*] - 表示每小时/分/秒（每秒执行）
[12:*:*] - 每天12点的每秒执行
[*:30:*] - 每小时30分的每秒执行
[*:*:45] - 每分钟45秒执行
3. 时分格式 (2个部分，用 : 分隔)
[时:分] 例如： [12:30]
[*:*] - 表示每小时/分（每分钟执行）
[12:*] - 每天12点的每分钟执行
[*:30] - 每小时30分执行
4. 星期格式 (1个部分)
[0] - 周日
[1] - 周一
[2] - 周二
[3] - 周三
[4] - 周四
[5] - 周五
[6] - 周六




杀怪经验获得计算公式：
（杀怪经验 *（引擎配置倍率+地图倍率）+ 技能额外获得）* 玩家倍率
说明：引擎配置倍率在server.txt 文件里的 ExpFactor = 100 。
地图倍率是在地图配置文件里设置：[define]下直接定义 expfactor = 100 即可。
玩家倍率可以使用 SETEXPFACTOR 倍率  。解释，倍率都是100为1倍。



物品触发说明
ItemScript.txt文件
#物品名=捡物品脚本,扔物品脚本,使用脚本
宝盒=20|180000|@box.pickup,10|180000|@box.lose,
注意：只有扔物品脚本包含，次数|时间间隔|脚本名，时间间隔为秒单位。
扔物品脚本这里有3种写法：第一种，只有脚本名。第二种，包含时间间隔，也就是延时执行。第三种，三样都包含。

怪物掉落数据说明
MonItems文件夹下文件
# 几率 物品名 最小数 最大数
1/1 金币 1000 2000
1/100 黑暗之戒 解释：随系统配置随机持久和属性。
1/100 *黑暗之戒 解释：随机特殊随机持久随机属性。（默认 配置的值减5 - 配置的值 之间随机一个数去执行逻辑。）
1/100 *黑暗之戒 3 5 解释：随机特殊随机持久随机属性（按照设置的参数，在 3 - 5之间随机一个数去执行逻辑。）
注意：特别注意物品名字加星号的作用，它是开启掉落物品的属性随机。持久随机是一定会执行，也要看几率。
